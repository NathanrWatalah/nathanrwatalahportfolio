DHCP and DNS Troubleshooting

Network troubleshooting guide

Knowledge Base / Network / DHCP and DNS Troubleshooting

Problem

Practical checks for DHCP and DNS troubleshooting. Follow the safe steps below and contact your support team if the issue continues.

These are general troubleshooting checks, not a confirmed diagnosis. Follow your organization's procedures and stop if a step could risk data, safety, or managed equipment.

Symptoms to check

  • Users receive an invalid or duplicate IP address, cannot resolve names, or cannot reach services by name.
  • The issue may affect one device or many users on the same subnet.

Possible causes

  • DHCP scope exhaustion, address conflicts, or server outages can result in broken connectivity.
  • DNS server errors, stale records, or local resolver issues may prevent name lookup.

Resolution

  1. Check whether the affected device has a valid IP address, gateway, and DNS server. Confirm the issue is limited to one device or several devices on the same network.
  2. Use built-in tools to verify the assigned IP address and to test DNS by sending a lookup for a known hostname. If the IP is in the wrong range, a DHCP or network policy issue is likely involved.
  3. Review the DHCP server lease status, scope settings, and whether the device is receiving the correct default gateway and DNS values.
  4. If DNS fails, test a direct IP connection to confirm the issue is name resolution rather than general connectivity. Review the DNS server health and any recent record changes.
  5. Escalate to the network or server team with the exact IP, subnet, DNS test results, and scope or server status information so they can isolate the cause quickly.

Prevention and preparation

  • Keep DHCP scopes and IP reservations documented and under active monitoring.
  • Verify DNS changes carefully and monitor outage or misconfiguration alerts promptly.
