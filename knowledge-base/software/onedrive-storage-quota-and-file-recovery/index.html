OneDrive Storage Quota and File Recovery

Software troubleshooting guide

Knowledge Base / Software / OneDrive Storage Quota and File Recovery

Problem

A user reports that OneDrive is full, files are missing, or changes are not syncing after a storage warning or file deletion event.

Storage and recovery issues often happen when a user exceeds quota, a file is deleted from the cloud or device, or a conflict occurs between local and cloud versions.

Symptoms to check

  • The user receives a “storage is full” warning or cannot upload new files.
  • Files appear missing, duplicated, or marked as needing conflict resolution.
  • Recent file changes do not show in SharePoint or Teams after upload.

Possible causes

  • The Microsoft 365 storage quota has been reached.
  • A file was deleted from the local device or cloud and needs restore.
  • Sync conflicts or file naming issues are blocking the latest version from updating.

Resolution

  1. Check whether the user’s storage limit has been reached and whether there are large files or shared content using the available quota.
  2. Open the OneDrive sync status and review any conflicts, pending files, or upload errors before making changes to the user's local files.
  3. If files are missing, use the Restore or Recycle Bin options in OneDrive or SharePoint to recover recent deletions before looking at older versions.
  4. Verify file names and storage paths for unsupported characters or restrictions that might prevent syncing. Move the files to a simpler folder path if necessary.
  5. After the quota or sync issue is corrected, confirm the user can upload, view, and open the expected files across their devices.

Prevention and preparation

  • Warn users about storage limits before they begin large file transfers or syncing.
  • Encourage regular cleanup of old files or archived content to maintain smooth OneDrive access.
  • Document the recovery workflow to reduce delay during file-loss incidents.
